# Web Portal Bounded Context: ArtifyBharat (MoSJE)

## Architecture Overview
The Web Portal provides the responsive web client and administrative management interfaces for Artify Bharat under the **Ministry of Social Justice and Empowerment (MoSJE)** (SIH PS 26090).

## Core Interfaces
1. **Buyer Verification Portal**:
   - 6-Character Shortcode (`A7X-9B2`) and Vector QR Code resolver.
   - MoSJE & e-Shram Verified Artisan Origin cards.
   - Work-In-Progress (WIP) loom photo proof with GPS & Timestamp lock.
   - Native dialect voice story streaming.
   - 100% transparent 4-part Fair Price Breakdown (Raw Materials + Fair Labor + Direct Profit + Packaging).
   - Anti-Fraud Feedback Loop (**"🚩 Report Fake / Machine-Made"**) with direct escalation to MoSJE Nodal Officers and Peer Review Jurors.

2. **Artisan & SHG Leader Web Hub**:
   - **Dual-Role Access Engine**: Artisan Direct Mode vs Aggregator / SHG Leader Mode (multi-tenant coordinator).
   - Browser Media Capture (HTML5 `MediaDevices API`) with 1:1 aspect ratio constraint and gyro leveling.
   - Live Geolocation API & UTC timestamp locking.
   - Zero-Literacy Voice Engine (Web Speech API / Bhashini Audio Stream).
   - Interactive Fair Wage & Dynamic Pricing slider.
   - **Web Bluetooth API** 58mm ESC/POS thermal printer bridge for instant sticky label printing.
   - One-Tap Multi-Channel publish (GeM, ONDC, WhatsApp Web).
   - 'Ask Dadi' voice assistant with **PM-DAKSH** skill upskilling nudges.
   - Browser `IndexedDB` offline drafts and `ServiceWorker` background sync queue.

3. **MoSJE Admin & Nodal Officer Dashboard**:
   - **Live District Economic Heatmap**: Geospatial analytics across national craft clusters tracking direct wage disbursement and active artisans.
   - **Zero-Trust Anti-Corruption & Peer-Review Logs**: Real-time audit logs of 3-artisan peer jury verdicts and counterfeit anomaly flags.
   - **PM-DAKSH Skill Upskilling Analytics**: Certified artisan counts and wage growth telemetry.
   - **Predictive Demand AI (DemandForecast)**: Festive demand forecasting for strategic cluster inventory planning.
