# Triage Labels

The Matt Pocock engineering skills speak in terms of five canonical triage roles. This file maps these roles to label strings in the ArtifyBharat GitHub issue tracker.

| Label in mattpocock/skills | Label in tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation, architectural review, or physical credentials |
| `wontfix` | `wontfix` | Decided not to action |
